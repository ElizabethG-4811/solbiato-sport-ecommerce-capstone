# Solbiato Sport Streetwear (Capstone Project)

### Project Overview
I wanted to focus my final capstone project on a brand that I have a real personal connection to. Growing up in the DMV area, I saw firsthand how popular Solbiato Sport was between 2006 and 2010. People loved wearing complete matching outfits—everything from the skull caps and t-shirts down to the track pants had the exact same design with reflective gear and color scheme. It felt highly exclusive because it was only sold out of just one physical location in the luxury neighborhood Georgetown, Washington, D.C. 

What really interests me is how they design their clothing pieces to perfectly match across different items. I wanted to use data analytics to understand how they structure and market their products to encourage people to buy whole outfits instead of just one piece, and see how that brand strategy has developed over time.

### Data Analysis
There was no ready-made dataset available for this brand online, so I had to set up and engineer the entire data pipeline myself:
* **Automated Web Scraping:** I wrote a custom automated web scraper using Python in VS Code to gather live product data straight from the website.
* **The Final Data:** My script ran successfully for over 50 minutes and collected a real-time list of 755 products, organizing their names, categories, and matching design names.
* **Data Cleaning:** I cleaned up the raw files using Pandas and fixed the pricing text columns so they can be easily read by visual tools without throwing any errors.

###  Visualizations and Dashboards
Since I am a visual learner and this streetwear brand is all about style and design, I will be using **Tableau** and **PowerPoint** to build an interactive, lookbook-style presentation. 
* **Products:** Counting how many tops, bottoms, and accessories they stock to keep outfit options balanced.
* **Pricing Trends:** Looking at how their total catalog value shifted from $47k to $45k to see how they use markdowns to help sell full outfits from their website.
* **Google Trends:** Tracking 22 years of internet search popularity to prove how demand stays tied directly to the DMV community.
